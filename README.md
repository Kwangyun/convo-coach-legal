# convo-coach-legal

답톡(Convo Coach) 앱의 개인정보처리방침과 이용약관을 공개하는 저장소입니다.

**이 저장소의 index.md를 직접 고치지 마십시오.** 원본은 앱 저장소의
`legal/privacy-policy.md` 와 `legal/terms.md` 이고,
`tools/build-legal-site.py` 가 여기로
만들어냅니다. 여기서 고치면 앱 안에 적힌 방침과 공개된 방침이 달라집니다.

공개 주소
- 처리방침: https://kwangyun.github.io/convo-coach-legal/
- 이용약관: https://kwangyun.github.io/convo-coach-legal/terms/
